The AVG() Function

15 Min Read • Module 1: Basics

The University Exam Grading Curve Analogy

Imagine a university physics professor calculating final exam performance for a lecture hall of 200 students:

  • 1. Diverse Test Scores:: Students score 95%, 82%, 76%, 58%, and 100%.
  • 2. Absent Students (NULL):: A student who was hospitalized and missed the exam receives no grade (NULL), rather than a zero (0%).
  • 3. The Fair Average:: The professor sums the scores of everyone who took the test and divides strictly by the number of students who showed up: SUM / COUNT(scores).
  • 4. Preserving the Curve:: If the professor mistakenly counted absent students as zeros, the class average would plunge unfairly!

The AVG() function computes the arithmetic mean across numeric records, automatically dividing by the count of non-null rows.

Syntax & Statement Grammar

The standard SQL syntax and pattern rules for The AVG() Function:

SQL Syntax Grammar • avg.sql 
-- 1. Basic Arithmetic Mean
SELECT AVG(salary) AS raw_average_salary
FROM employees;

-- 2. Rounded Arithmetic Mean for Currency Display
SELECT ROUND(AVG(salary), 2) AS clean_average_salary
FROM employees;

-- 3. Filtered Average with WHERE Clause
SELECT ROUND(AVG(order_total), 2) AS avg_enterprise_order_value
FROM customer_orders
WHERE account_tier = 'ENTERPRISE';

-- 4. Conditional Average with CASE Expression
SELECT 
    ROUND(AVG(CASE WHEN department = 'Engineering' THEN salary END), 2) AS avg_eng_salary,
    ROUND(AVG(CASE WHEN department = 'Sales' THEN salary END), 2) AS avg_sales_salary
FROM employees;

Core Concepts & Engine Mechanics

The AVG() aggregate function calculates the arithmetic mean (sum divided by count) of all non-null values in a numeric column or expression. Like SUM(), it returns NULL if the dataset contains zero matching rows.

  • The Critical NULL Division Rule: AVG() computes: SUM(col) / COUNT(col). It does NOT divide by COUNT(*). Rows containing NULL are completely excluded from both numerator and denominator.
  • Integer Truncation Trap: In engines like SQL Server and SQLite, averaging integer columns performs integer division (e.g. 5 / 2 = 2); cast to FLOAT or DECIMAL for precision.
  • Pairing with ROUND(): Unrounded averages produce numbers with 14 decimal digits (e.g. 42.85714285714286); always pair with ROUND(AVG(col), 2) for clean display.
  • Outlier Sensitivity: The arithmetic mean is highly sensitive to extreme outliers; compare AVG() with median metrics in skewed distributions.

Detailed Technical Breakdown & Syntax Comparison

Calculation Method SQL Formula Divisor Scope Handling of NULL Rows Result Accuracy
Standard AVG() AVG(col) Non-null rows only Skipped in numerator and divisor Accurate mean of populated data
Zero-Filled Average AVG(COALESCE(col, 0)) All rows in table Converts NULL to 0, increasing divisor Includes unpopulated rows as zeros
Rounded Average ROUND(AVG(col), 2) Non-null rows only Skipped Production UI currency standard
Integer Cast Average AVG(CAST(int_col AS NUMERIC)) Non-null rows only Skipped Prevents integer truncation errors

The Null Divisor Trap: AVG(col) vs AVG(COALESCE(col, 0))

Understanding how NULL affects the divisor in an average calculation is a classic senior database engineering interview question:

  • Scenario: Consider a table with 4 rows: 100, 200, 300, and NULL.
  • Case A (Standard AVG): AVG(val) evaluates: (100 + 200 + 300) / 3 = 200.00. The NULL row is ignored completely.
  • Case B (Coalesced AVG): AVG(COALESCE(val, 0)) evaluates: (100 + 200 + 300 + 0) / 4 = 150.00.
  • Business Decision: Always confirm with stakeholders whether missing data represents 'not evaluated' (Case A) or 'zero activity' (Case B).

Real-World Practical Scenario

E-Commerce Customer Satisfaction & Delivery Speed: Analyze fulfillment times and customer review star ratings to audit vendor delivery performance SLAs.

Production Queries • E-Commerce Customer Satisfaction & Delivery Speed 
/* ========================================================
   Sample Dataset: vendor_fulfillments
   delivery_id | vendor_code | delivery_hours | rating_stars | status
   ------------+-------------+----------------+--------------+-----------
   9001        | FAST_SHIP   | 24.5           | 5            | DELIVERED
   9002        | FAST_SHIP   | 36.0           | 4            | DELIVERED
   9003        | SPEEDY_LOG  | 72.0           | 2            | DELIVERED
   9004        | FAST_SHIP   | 18.5           | 5            | DELIVERED
   9005        | SPEEDY_LOG  | 48.0           | NULL         | DELIVERED
   ======================================================== */

-- Requirement 1: Calculate global average fulfillment turnaround time
SELECT ROUND(AVG(delivery_hours), 1) AS avg_turnaround_hours
FROM vendor_fulfillments;
-- Matches: 39.8 hours mean fulfillment duration

-- Requirement 2: Compare average review rating for FAST_SHIP vendor
SELECT 
    COUNT(*) AS total_shipments,
    ROUND(AVG(rating_stars), 2) AS fast_ship_avg_rating
FROM vendor_fulfillments
WHERE vendor_code = 'FAST_SHIP';
-- Matches: 3 shipments, 4.67 average rating stars

-- Requirement 3: Audit SPEEDY_LOG review average (Demonstrates NULL exclusion)
SELECT 
    COUNT(*) AS total_deliveries,
    COUNT(rating_stars) AS rated_deliveries,
    AVG(rating_stars) AS speedy_avg_rating
FROM vendor_fulfillments
WHERE vendor_code = 'SPEEDY_LOG';
-- Matches: 2 total, 1 rated, avg rating: 2.0 (The NULL rating is excluded from divisor)

-- Requirement 4: High-efficiency carrier identification (Delivery < 30 hours)
SELECT ROUND(AVG(rating_stars), 2) AS rapid_delivery_avg_rating
FROM vendor_fulfillments
WHERE delivery_hours < 30.0;
-- Matches: 5.00 star average rating for rapid deliveries under 30 hours

Chapter Summary

The AVG() function computes the arithmetic mean across numeric records, automatically filtering out NULL values and providing essential statistical insights for analytics dashboards.

  • Non-Null Divisor: AVG() automatically divides by COUNT(col), skipping NULL values from both the sum and the divisor.
  • Cast Integer Columns: Cast integer columns to FLOAT or NUMERIC before averaging to prevent truncation in engines that perform integer division.
  • Always Pair with ROUND(): Format outputs using ROUND(AVG(col), 2) to eliminate messy 14-decimal float outputs.
  • Outlier Awareness: Keep in mind that extreme values distort arithmetic averages; compare with median calculations where appropriate.
  • Zero vs NULL Semantics: Use AVG(COALESCE(col, 0)) only if missing entries should actively count as zero in the divisor.
