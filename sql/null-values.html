NULL Values & Three-Valued Logic

15 Min Read • Module 1: Basics

The Empty Box vs Zero Analogy

Imagine three boxes on a table: Box 1 contains a piece of paper with the number 0. Box 2 contains an empty string (an empty paper). Box 3 is sealed and completely unknown—you have no idea whether something exists inside it or not.

Box 3 represents NULL. NULL is not zero, and NULL is not empty text. It represents missing, absent, or unknown information.

Syntax & Statement Grammar

The standard SQL syntax and clause requirements for NULL Values & Three-Valued Logic:

SQL Grammar • null-values.sql 
-- Correct syntax for testing NULL:
SELECT * FROM table_name WHERE column_name IS NULL;
SELECT * FROM table_name WHERE column_name IS NOT NULL;

-- ❌ NEVER USE = NULL:
-- WHERE column_name = NULL; (Always evaluates to UNKNOWN!)

Core Concepts & Engine Mechanics

In relational databases, NULL denotes the absence of data. Because SQL implements Three-Valued Logic (TRUE, FALSE, UNKNOWN), standard equality checks like col = NULL or col != NULL never evaluate to true.

You must always use the specialized predicates IS NULL and IS NOT NULL to verify whether a column holds a null value. When performing calculations or joins, nulls require defensive handling via COALESCE().

Real-World Practical Scenario

Finding Users Missing Emergency Contact Phone Numbers: Audit customer records to isolate profiles that haven't verified phone contact details.

Production Example • Finding Users Missing Emergency Contact Phone Numbers 
SELECT user_id, first_name, email, phone_number
FROM user_profiles
WHERE phone_number IS NULL
   OR emergency_contact IS NULL;

Chapter Summary

NULL in SQL denotes the absence of data rather than zero or an empty string, governed by Three-Valued Logic. Using IS NULL and IS NOT NULL instead of standard equality operators prevents critical logical bugs in analytics.

  • Missing Data: NULL signifies unknown, unassigned, or absent information—not zero and not an empty string.
  • Three-Valued Logic: Comparisons with NULL evaluate to UNKNOWN; col = NULL is always false in practice.
  • Proper Predicates: Always use IS NULL or IS NOT NULL to test for presence of null values.
  • Aggregation Behavior: Statistical aggregate functions (SUM, AVG, COUNT(col)) ignore null values during computation.
