SQL Aggregate Functions Overview

15 Min Read • Module 1: Basics

The Dashboard Instrument Cluster Analogy

When driving a car, you don't inspect every single drop of fuel burnt or tire rotation. You glance at the dashboard cluster: your speedometer displays your average speed, and the odometer displays your total mileage.

Aggregate functions condense thousands of individual records into high-level business summaries like totals, averages, and extremes.

Syntax & Statement Grammar

The standard SQL syntax and clause requirements for SQL Aggregate Functions Overview:

SQL Grammar • aggregate-functions.sql 
SELECT 
    COUNT(*) AS total_rows,
    SUM(amount) AS total_revenue,
    AVG(amount) AS average_sale,
    MIN(amount) AS lowest_sale,
    MAX(amount) AS highest_sale
FROM sales_transactions;

Core Concepts & Engine Mechanics

Aggregate functions perform calculations on multiple values across rows and return a single summary value. Standard SQL provides five foundational aggregate functions: COUNT, SUM, AVG, MIN, and MAX.

Crucially, all aggregate functions (except COUNT(*)) completely ignore NULL values during calculation. When querying individual columns alongside aggregates, you must group the non-aggregated columns using GROUP BY.

Real-World Practical Scenario

Complete Departmental Compensation Dashboard: Calculate complete workforce metrics in a single query.

Production Example • Complete Departmental Compensation Dashboard 
SELECT 
    COUNT(employee_id) AS active_headcount,
    ROUND(AVG(salary), 2) AS mean_compensation,
    SUM(salary) AS total_payroll_expense,
    MIN(salary) AS floor_salary,
    MAX(salary) AS ceiling_salary
FROM corporate_employees;

Chapter Summary

Aggregate functions synthesize thousands of rows into decisive scalar summary metrics. Combining aggregates with GROUP BY forms the cornerstone of executive dashboards, financial auditing, and business intelligence.

  • Multi-Row Summary: Aggregates condense multiple rows into a single scalar metric.
  • The Big Five: COUNT (tally), SUM (addition), AVG (mean), MIN (lowest), MAX (highest).
  • NULL Elimination: Aggregates ignore null values; SUM on nulls returns NULL unless wrapped with COALESCE.
  • Grouping Requirement: Any non-aggregate column in the SELECT clause must appear in the GROUP BY clause.
