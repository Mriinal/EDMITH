Scoring & Grading Rules

Scores are awarded based on assessment question difficulty across MCQ and Coding tests.

Easy
MCQ: 1 Mark / question
Coding: 3 Marks / problem

Fundamental syntax, SELECT filters, and basic single-table queries.

Medium
MCQ: 3 Marks / question
Coding: 6 Marks / problem

Aggregate functions, GROUP BY, multi-table JOINs, and subqueries.

Hard
MCQ: 6 Marks / question
Coding: 12 Marks / problem

Window functions, complex CTEs, transactions (ACID), and query optimization.
