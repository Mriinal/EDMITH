SQL Aliases (The AS Keyword)

15 Min Read • Module 1: Basics

The Stage Name Analogy

An author born with a long, complex name writes best-selling novels under a concise, memorable pen name. Readers and bookstores refer to the author by their pen name on the book cover.

SQL Aliases provide temporary, concise names to columns and tables during a query's execution.

Syntax & Statement Grammar

The standard SQL syntax and clause requirements for SQL Aliases (The AS Keyword):

SQL Grammar • aliases.sql 
-- Column Alias:
SELECT column_name AS display_name FROM table_name;

-- Table Alias:
SELECT t.col1, t.col2 FROM very_long_table_name AS t;

Core Concepts & Engine Mechanics

The AS keyword creates temporary aliases for columns, expressions, or tables. Aliases exist only for the duration of the query.

Crucially, column aliases created in SELECT cannot be referenced in WHERE or HAVING clauses because filtering executes prior to projection in logical query execution.

Real-World Practical Scenario

Disambiguating Multi-Table Join Columns with Aliases: Join customers and orders while providing clear column headers for reporting.

Production Example • Disambiguating Multi-Table Join Columns with Aliases 
SELECT 
    c.customer_id AS account_id,
    c.email AS customer_email,
    o.order_id AS invoice_number,
    o.order_amount AS total_billed
FROM customers AS c
JOIN orders AS o ON c.customer_id = o.customer_id;

Chapter Summary

SQL aliases created via the AS keyword assign clear, temporary identities to complex expressions, aggregated metrics, and joined tables, dramatically enhancing query readability and downstream code maintainability.

  • Temporary Renaming: Assigns readable, query-scoped names to columns and source tables.
  • Disambiguation: Resolves naming conflicts when multiple joined tables share identical column names.
  • Clause Visibility: Column aliases are visible in ORDER BY, but invisible in WHERE and HAVING.
  • Derived Tables: Table aliases are mandatory when querying derived subqueries in the FROM clause.
