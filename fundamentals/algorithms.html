What is an Algorithm?

8 Min Read • Beginner • Language Agnostic

1. The Definition of an Algorithm

An algorithm is a finite, well-ordered, deterministic sequence of unambiguous instructions designed to perform a specific computational task, process data, or solve a problem.

The word "algorithm" derives from the 9th-century Persian mathematician Muhammad ibn Musa al-Khwarizmi, who developed foundational rules for arithmetic. In computer science, an algorithm is completely independent of any programming language: it is the pure conceptual logic that underlies a solution.

2. Everyday Real-World Analogies

  • A Culinary Recipe: Lists ingredients (inputs), specifies temperature and mixing steps (process), and yields a prepared dish (output).
  • GPS Navigation: Reads starting coordinates and destination (inputs), computes shortest path avoiding traffic (process), and gives turn-by-turn directions (output).
  • Assembling Flat-Pack Furniture: Follows numbered diagrammatic steps in strict sequential order. Skipping Step 2 to do Step 5 results in structural failure.

3. The 5 Essential Properties of a Valid Algorithm

In theoretical computer science, a procedure must satisfy five rigorous criteria to be classified as a valid algorithm:

Property Requirement Why It Matters
1. Unambiguous (Definiteness) Every step must be clearly and uniquely defined. Computers cannot interpret vague phrases like "stir until ready".
2. Finiteness Must terminate after a countable number of operations. A program that never stops is broken (infinite freeze).
3. Inputs Accepts zero or more well-defined external inputs. Specifies the operational boundaries and data domain.
4. Outputs Produces at least one well-defined result or state change. Without an output, the computation served no purpose.
5. Feasibility (Effectiveness) Each instruction must be physically computable. Must be executable within finite hardware memory and time.

4. The Concept of Algorithmic Efficiency

There can be multiple different algorithms to solve the exact same problem. For example, you can search for a name in a phone book by checking every single page from front to back, or by opening the book in the middle and dividing it in half repeatedly (binary search).

Both algorithms are correct and produce the exact same answer. However, the first takes hours for a large directory, while the second takes less than a second. In computer science, we evaluate algorithms based on Time Complexity (how execution time grows as input size increases) and Space Complexity (how much memory is consumed).

5. Key Takeaways

  • An algorithm is a finite, unambiguous set of instructions to solve a problem.
  • Algorithms are completely language-independent.
  • A valid algorithm must be definite, finite, feasible, and produce at least one output.
  • Efficiency (time and memory) distinguishes good engineering from naive approaches.
