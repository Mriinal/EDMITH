Operators Concept

8 Min Read • Beginner • Language Agnostic

1. What is an Operator?

In computer programming, an operator is a special symbol or token that tells the computer's arithmetic logic unit (ALU) or runtime evaluator to perform a specific mathematical, relational, or logical manipulation on one or more values.

The values upon which an operator acts are called operands.

operand_a + operand_b

2. The Three Primary Operator Families

A. Arithmetic Operators

Perform universal mathematical operations on numerical data:

  • Addition (+): Computes the mathematical sum of two quantities.
  • Subtraction (-): Computes the difference between two quantities.
  • Multiplication (*): Computes the mathematical product.
  • Division (/): Computes the quotient. In integer division, the fractional part is truncated.
  • Modulo / Remainder (%): Yields the remainder resulting from integer division (e.g., 10 % 3 = 1). Widely used for determining even/odd status and cyclic intervals.

B. Relational (Comparison) Operators

Compare two operands and evaluate to a binary boolean truth value (true or false):

  • Equality (==): Evaluates to true if both operands represent the same value.
  • Inequality (!=): Evaluates to true if the operands are not equal.
  • Greater Than (>) / Less Than (<): Compares numerical magnitude.
  • Greater or Equal (>=) / Less or Equal (<=): Inclusive magnitude comparisons.

C. Logical (Boolean) Operators

Combine or invert boolean conditions to form complex decision expressions:

  • Logical AND: Evaluates to true only if both sub-conditions are true.
  • Logical OR: Evaluates to true if at least one sub-condition is true.
  • Logical NOT: Inverts the boolean truth value (changes true to false, and false to true).

3. Operator Precedence and Associativity

When an expression contains multiple operators, the computer must evaluate them in a strict, unambiguous order. Just like the mathematical order of operations (BODMAS / PEMDAS), programming languages follow operator precedence:

  1. Parentheses: Expressions enclosed in parentheses are always evaluated first.
  2. Multiplicative: Multiplication, division, and modulo precede addition and subtraction.
  3. Additive: Addition and subtraction.
  4. Relational: Comparisons (greater than, less than) precede equality checks.
  5. Equality: Equal and not equal checks.
  6. Logical: Logical AND precedes logical OR.

Universal Best Practice

Never rely solely on memory of subtle precedence rules when writing complex expressions. Always use explicit parentheses ( ) to make the evaluation order crystal-clear to both the computer and your fellow engineers.

4. Key Takeaways

  • Operators execute computations, comparisons, and logic on operands.
  • Arithmetic operators perform math; relational operators evaluate comparisons to true/false.
  • Logical operators combine conditions using Boolean algebra.
  • Precedence dictates evaluation sequence; parentheses eliminate ambiguity.
