# Third-Party Open Source Libraries & Licenses

This document outlines the third-party open-source components utilized in EDMITH's in-browser compilers and editors.

---

## 1. JSCPP (C/C++ In-Browser Interpreter)

- **Source**: https://github.com/felixhao28/JSCPP
- **Author**: Felix Hao and contributors
- **License**: MIT License
- **File**: `javascript/jscpp.min.js`
- **Purpose**: Powers the client-side C compilation and execution engine in the browser without requiring a backend server. Provides full support for standard I/O (`stdio.h`), pointers, control flow, functions, and arrays.

- **Source**: https://github.com/AlaSQL/alasql
- **License**: MIT License
- **File**: `javascript/alasql.min.js`
