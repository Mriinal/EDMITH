SQL Operators Reference

15 Min Read • Module 1: Basics

The Mechanic's Toolbox Analogy

A master auto mechanic doesn't use just a wrench. Their toolbox contains metric wrenches, torque sockets, pliers, and calipers. Each tool performs a precise mechanical operation on engine parts.

SQL operators are your mathematical and logical tools for performing arithmetic, comparisons, and boolean decisions on table data.

Syntax & Statement Grammar

The standard SQL syntax and clause requirements for SQL Operators Reference:

SQL Grammar • operators.sql 
-- Arithmetic Operators: +, -, *, /, % (Modulo)
SELECT price * 1.18 AS price_with_vat FROM products;

-- Comparison Operators: =, !=, <>, <, >, <=, >=
SELECT * FROM inventory WHERE stock_qty <= 10;

-- Logical Operators: AND, OR, NOT, IN, BETWEEN, LIKE, IS NULL
SELECT * FROM orders WHERE status = 'PAID' AND total > 100;

Core Concepts & Engine Mechanics

An operator is a reserved word or character used primarily in a SQL statement's WHERE clause to perform operations such as comparisons and arithmetic operations.

Operators fall into three fundamental classes:

  • Arithmetic Operators: + (Add), - (Subtract), * (Multiply), / (Divide), % (Modulo remainder).
  • Comparison Operators: =, <>, !=, >, <, >=, <=.
  • Logical Operators: ALL, AND, ANY, BETWEEN, EXISTS, IN, LIKE, NOT, OR, IS NULL.

Real-World Practical Scenario

Computing Modulo Batches and Arithmetic Discounts: Demonstrate arithmetic and comparison operators in order processing.

Production Example • Computing Modulo Batches and Arithmetic Discounts 
SELECT 
    order_id,
    order_id % 4 AS dispatch_conveyor_line, -- Modulo arithmetic
    unit_price,
    quantity,
    (unit_price * quantity) * 0.90 AS discounted_subtotal -- Arithmetic multiplication
FROM order_items
WHERE quantity > 5 AND unit_price >= 20.00;

Chapter Summary

SQL operators provide the fundamental computational tools for arithmetic calculations, equality comparisons, and boolean logic. Understanding precedence rules ensures predictable, robust query execution across all applications.

  • Three Operator Classes: Arithmetic (math calculations), Comparison (value matching), Logical (boolean decisions).
  • Modulo (% or MOD): Returns the integer remainder of division; great for round-robin dispatch queues.
  • Precedence Rules: Parentheses () have highest priority, followed by * and /, then + and -, then comparisons, AND, and OR.
  • Data Type Compatibility: Always ensure operands share compatible data types or cast them explicitly.
