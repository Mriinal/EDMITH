How Programs Execute

8 Min Read • Beginner • Language Agnostic

1. The Physical Engine: The Von Neumann Architecture

Nearly every modern computer—from smart watches and mobile phones to high-performance cloud servers—is built upon the architectural model formulated by mathematician John von Neumann in 1945.

The cornerstone principle of the Von Neumann Architecture is that both program instructions and program data share the same unified memory space (Random Access Memory, or RAM).

2. The Heartbeat of Computing: The Fetch-Decode-Execute Cycle

Once a program is loaded from persistent storage (SSD/Hard Drive) into RAM, the CPU runs an endless hardware loop known as the Instruction Cycle:

1. Fetch

The Control Unit looks at the Program Counter (PC) (also called the Instruction Pointer), which holds the RAM address of the next instruction, and loads that binary instruction into the CPU's Instruction Register.

2. Decode

The CPU decodes the binary opcode to understand what operation is required (e.g., ADD two values, LOAD data from memory, or COMPARE numbers) and identifies which operands are involved.

3. Execute

The Arithmetic Logic Unit (ALU) carries out the mathematical calculation or logical test. The result is stored back into an internal register or RAM, and the Program Counter advances to the next instruction.

3. Sequential Execution and Branching

By default, the CPU executes instructions in strict sequential order—one instruction directly after another. The Program Counter simply increments by the size of the instruction.

When a program encounters a decision (such as an IF condition) or a function call, the CPU performs a Branch Jump: it overrides the Program Counter with a completely new memory address, redirecting the execution flow to a different section of code.

4. Memory Speed Hierarchy

Not all memory is created equal. The CPU utilizes a hierarchy of memory storage speeds:

  • CPU Registers: Located directly inside the CPU core. Access time: ~0.5 nanoseconds. Extremely small capacity (hundreds of bytes).
  • CPU Cache (L1, L2, L3): High-speed on-die silicon buffer. Access time: ~1 to 10 nanoseconds. Holds frequently accessed data.
  • Main Memory (RAM): Primary volatile memory. Access time: ~50 to 100 nanoseconds. Fast, but volatile (erased when powered off).
  • Storage (SSD / NVMe): Persistent non-volatile storage. Access time: ~10,000 to 50,000 nanoseconds. Slower, but retains data permanently.

5. Key Takeaways

  • Programs must be loaded from storage into RAM before the CPU can execute them.
  • The CPU operates continuously on the Fetch-Decode-Execute instruction cycle.
  • The Program Counter tracks the memory address of the next instruction to execute.
  • Branching alters the Program Counter to implement conditional decision-making.
