NULL Values & Three-Valued Logic

15 Min Read • Module 1: Basics

The Unopened Amazon Mystery Package Analogy

Imagine receiving a sealed, unlabeled cardboard box on your front porch with no return address:

  • 1. It is NOT Empty:: The box is not empty (which would be an empty string '').
  • 2. It is NOT Zero:: The box does not contain the number zero (0 is a concrete mathematical integer).
  • 3. It is UNKNOWN:: The contents are completely unknown until someone opens and populates it.
  • 4. Equality Fails:: If your neighbor also receives an unopened mystery box, you cannot say both boxes contain the same item; NULL = NULL is UNKNOWN!

In SQL, NULL represents the total absence of a value. It is governed by Three-Valued Logic (TRUE, FALSE, UNKNOWN).

Syntax & Statement Grammar

The standard SQL syntax and pattern rules for NULL Values & Three-Valued Logic:

Query 1: NULL State Verification 
SELECT employee_id, first_name, manager_id
FROM employees
WHERE manager_id IS NULL;

Core Concepts & Engine Mechanics

In relational database theory, NULL is a special marker indicating that a data value does not exist in the database. NULL is not a value itself; it represents missing, unrecorded, or inapplicable data.

  • Three-Valued Logic (3VL): Boolean expressions in SQL evaluate to TRUE, FALSE, or UNKNOWN.
  • Equality Failure: Comparing anything to NULL with standard comparison operators (=, !=, <>, <, >) always results in UNKNOWN.
  • The IS NULL Operator: Because equality operators fail, ANSI SQL provides the dedicated IS NULL and IS NOT NULL predicates.
  • Aggregate Function Behavior: Standard aggregate functions (SUM, AVG, MIN, MAX, COUNT(col)) automatically ignore NULL values; only COUNT(*) counts rows with NULLs.

Why col = NULL Silently Breaks Database Applications

The single most common bug in novice SQL queries is filtering with WHERE col = NULL:

  • The Silent Failure: A WHERE clause only retains rows where the predicate evaluates strictly to TRUE. Since col = NULL evaluates to UNKNOWN, every single row is rejected!
  • No Error Thrown: The database engine throws no syntax error; it simply returns an empty result set, deceiving developers into thinking no data exists.
  • The Fix: Always use the designated keyword operators: WHERE col IS NULL or WHERE col IS NOT NULL.

Real-World Practical Scenario

Healthcare Clinical Patient Follow-up System: Identify discharged hospital patients whose post-op follow-up consultations or lab test results remain unrecorded.

Chapter Summary

NULL in SQL denotes missing or unassigned information governed by Three-Valued Logic, requiring explicit IS NULL and COALESCE handling to prevent critical query bugs.

  • Absence of Data: NULL indicates missing data; it is completely distinct from numeric zero or empty string ''.
  • Never Use = NULL: Always use IS NULL and IS NOT NULL; standard equality comparisons (=, !=) with NULL evaluate to UNKNOWN.
  • Arithmetic Contamination: Any arithmetic operation with NULL (5 + NULL) results in NULL; use COALESCE to supply fallbacks.
  • Aggregate Exclusion: Aggregate functions (SUM, AVG, MIN, MAX) automatically ignore NULL rows during calculation.
  • Three-Valued Truth Logic: Remember that WHERE clauses reject rows evaluating to UNKNOWN just as they reject FALSE.
